## Milestone 7 API Documentation

Swagger UI:
http://localhost:8080/swagger-ui/index.html#/

REST API Endpoints

GET /api/products
Returns all product information from the MySQL products table.

GET /api/products/{id}
Returns one product by product ID.

Example URLs:
http://localhost:8080/api/products
http://localhost:8080/api/products/1
